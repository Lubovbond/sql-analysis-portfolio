# Портфолио: SQL-аналитика в E-commerce

В этом репозитории собраны мои кейсы по анализу данных интернет-магазина.

## Кейс 1: Сегментация пользовательских сессий
Задача: Разбить поток событий на сессии с порогом в 30 минут.
Зачем это нужно: Чтобы понять, сколько времени пользователи проводят на сайте за один визит и какие действия совершают внутри одной сессии.
Техническая сложность: Использование многоуровневых CTE и оконных функций для работы с состоянием данных.
