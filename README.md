# Комплексный анализ баз данных и решение бизнес-задач на SQL 📊

## 📌 Описание проекта
Данный репозиторий является моим интерактивным портфолио по SQL-аналитике. В нём собраны практические скрипты и аналитические запросы, моделирующие реальные продуктовые и маркетинговые задачи бизнеса. 

Вместо простых выборок код сфокусирован на извлечении ценных инсайтов, когортном анализе, сегментации пользователей и расчете ключевых метрик эффективности (KPI).

---

## 🛠️ Технологический стек и навыки
* **СУБД:** `PostgreSQL` / `ClickHouse`
* **Основные конструкции:** Сложные объединения (`LEFT/INNER/FULL JOIN`), подзапросы и обобщенные табличные выражения (`WITH / CTE`), группировки и фильтрация агрегатов (`GROUP BY`, `HAVING`).
* **Аналитические инструменты:** Оконные функции (`ROW_NUMBER`, `RANK`, `LEAD/LAG`, скользящие агрегаты), логические ветвления (`CASE WHEN`), работа со строками и датами.

---

## 📐 Реализованные бизнес-задачи и исходный код:

### 1. Маркетинговая и продуктовая аналитика (Product Analytics)
* **[🔗 Когортный анализ и Retention Rate](Kogortniy_analiz.sql)** — комплексный скрипт для расчета удержания пользователей (Retention) по неделям и месяцам, позволяющий оценивать возвращаемость клиентов в динамике.
* **[🔗 Продуктовая воронка (Conversion Funnel)](Voronka_prodaj.sql)** — построение пошаговой воронки продаж интернет-магазина (от клика до регистрации, добавления в корзину и финальной оплаты).

### 2. Финансовый и операционный аудит (Fintech & E-commerce)
* **[🔗 Анализ динамики выручки MoM/YoY](Dinamika_viruchki.sql)** — расчет темпов роста доходов бизнеса месяц к месяцу и год к году с использованием оконного смещения (`LAG`).
* **[🔗 Сегментация клиентов (RFM-анализ)](RFM_segmentacia.sql)** — расчет метрик Recency (давность), Frequency (частота) и Monetary (сумма) с последующим распределением клиентской базы по сегментам для точечного маркетинга.

### 3. Оптимизация и архитектура запросов
* Все скрипты написаны с использованием **CTE (Common Table Expressions)**, что делает код модульным, легко читаемым для команды и оптимизированным с точки зрения скорости выполнения запросов в СУБД.
