# SQL Аналитика: Исследование данных E-commerce

В этом репозитории представлены мои решения практических задач по анализу данных интернет-магазина. Проекты охватывают ключевые бизнес-метрики: от сегментации пользователей до финансовой динамики.

## Изученные технологии
* **СУБД:** PostgreSQL
* **Инструменты:** CTE (временные таблицы), Оконные функции (`LAG`, `SUM OVER`, `DENSE_RANK`), Агрегация, Сложные джоины, Операторы `EXISTS/NOT EXISTS`.

---

## Кейсы в репозитории:

### 1. Анализ пользовательских сессий ([Код здесь](./customer_sessions.sql))
* **Бизнес-задача:** Разбить поток кликов на отдельные сессии (визиты) с порогом неактивности в 30 минут.
* **Ценность для бизнеса:** Помогает понять среднюю длительность визита и «путь клиента» до совершения покупки.
* **Техническая фишка:** Использование «матрешки» из CTE для расчета интервалов и накопительного суммирования флагов.

### 2. Анализ премиальных брендов ([Код здесь](./premium_brands_analysis.sql))
* **Бизнес-задача:** Выявить бренды, средняя цена которых на 20% и более превышает среднюю цену по всему ассортименту.
* **Ценность для бизнеса:** Инструмент для отдела закупок и маркетинга для выделения премиум-сегмента и корректировки ценовой стратегии.
* **Техническая фишка:** Использование вложенных подзапросов в блоке `HAVING` для сравнения агрегатов разного уровня.

### 3. Динамика выручки по категориям ([Код здесь](./monthly_revenue_dynamics.sql))
* **Бизнес-задача:** Рассчитать ежемесячный доход и накопленную выручку за все предыдущие периоды (Month-over-Month).
* **Ценность для бизнеса:** Визуализация темпов роста компании и отслеживание сезонности в разных товарных категориях.
* **Техническая фишка:** Настройка сложной рамки окна `ROWS BETWEEN UNBOUNDED PRECEDING AND 1 PRECEDING` для корректного расчета накопленных итогов без учета текущего месяца.
