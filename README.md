# Комплексный анализ баз данных и решение бизнес-задач на SQL & Python 📊

## 📌 Описание проекта
Данный репозиторий является моим интерактивным портфолио по продуктовой и коммерческой аналитике. В нём собраны практические скрипты, моделирующие реальные задачи e-commerce и ритейла. Код сфокусирован на извлечении ценных инсайтов, когортном анализе, оценке сессий и расчете ключевых метрик эффективности (KPI).

---

## 🛠️ Технологический стек и навыки
* **Языки и библиотеки:** `SQL (PostgreSQL)`, `Python (Pandas, NumPy)`
* **Основные конструкции:** Сложные объединения (`JOIN`), подзапросы, обобщенные табличные выражения (`WITH / CTE`), группировки и фильтрация агрегатов (`GROUP BY`, `HAVING`).
* **Аналитические инструменты:** Оконные функции, логические ветвления (`CASE WHEN`), работа со строками, датами и временными интервалами.

---

## 📐 Реализованные бизнес-задачи и исходный код:

### 1. Коммерческая и финансовая аналитика (Commercial Analytics)
* **[🔗 Анализ динамики ежемесячной выручки](monthly_revenue_dynamics.sql)** — расчет темпов роста доходов бизнеса от месяца к месяцу (MoM) с использованием оконных функций.
* **[🔗 Факторный анализ продаж премиальных брендов](premium_brands_analysis.sql)** — исследование маржинальности, объемов сбыта и вклада дорогого сегмента товаров в общую прибыль компании.
* **[🔗 Оптимизация региональных продаж](optimized_regional_sales.sql)** — агрегированные выборки по географическим зонам для поиска наиболее эффективных филиалов и рынков сбыта.

### 2. Продуктовая аналитика и поведение пользователей (Product Analytics)
* **[🔗 Анализ пользовательских сессий](customer_sessions.sql)** — исследование логов активности клиентов, подсчет длительности сессий, частоты визитов и базовых метрик вовлеченности.
* **[🔗 Расчет когорт и юнит-экономики на Python](unit_economics_cohorts.py)** — кастомный скрипт для автоматического формирования когорт пользователей, оценки удержания (Retention) и расчета базовой юнит-экономики на Pandas.
